# 验收样例：日常口语中英对照

用于手工验收「朗读文本」「翻译并朗读」的自然度。

| 场景 | 中文 | English |
|---|---|---|
| 起床 | 而是直接 | I need to get up. |
| 洗脸 | 洗脸 | Let me wash my face. |
| 出门 | 出门 | I'm heading out. |
| 到公司 | 到公司 | I'm at work. |
| 开会 | 开会 | We're about to start the meeting. |
| 遇到 Bug | 遇到 Bug | Something's wrong with the API. |
| 不确定 | 不确定 | I'm not sure about that. |
| 请求别人 | 请求别人 | Could you take a look at this? |

这才是真正的：English as a language
